# 灵台 LingTai OS

> ## 让任何 AI 按**验证过的方法**做事，而不是按它猜的。
>
> 换个会话、换个模型、换台电脑——规矩、记忆、进度都还在。
> **而且用的人越多，这套方法越准。**
>
> v0.3.0 · Windows 64 位 · 零依赖 · 零遥测 · 记忆全在你本地

## 一分钟看懂

你每天都在重复这三件事：

1. 开个新会话 → 从头解释项目、约束、上次决定了什么
2. AI 自信地说"应该是这样"→ 你信了 → 半小时后发现不是
3. 同一个坑，三个月后换个项目又踩一遍

灵台干的事：把你的项目状态**机器生成**（不信任何人手写的进度），
生成一段能粘进**任何 AI** 的开工指令，
并把每次踩的坑连同"怎么防"一起钉进一个**会自我淘汰**的经验库。

```
点项目卡 → 复制「继续做」指令 → 粘给任何 AI → 它知道该干什么、不该干什么
```

不改你的工作流，不上传你的代码，不需要订阅任何 API。

## 为什么它和"AI 记忆工具"不是一回事

市面上的 agent memory 工具解决的是**存储**：让 AI 记住你说过什么。

灵台解决的是**方法**：让 AI 按对的方式做事——先实证再开口、说不出服务哪个目标就不做、
完工判据不能是过程量、兜底必须出声。这些不是编出来的，是一条条实战踩出来的坑
和一套被反复验证的纪律。

**关键差别**：记忆是你一个人的，方法是所有人共用的。
你记的通用坑可以[回流进主库](#让方法变得更准)，进来的每一条都让所有人的 AI 更靠谱一点。
**这是这个产品唯一会随用户增长而变强的东西。**

## 隐私承诺（第一版就写死，不靠以后补）

- **零遥测**：本软件不含任何上报代码，你的使用数据没有出口
- **记忆全本地**：所有记忆/状态/轨迹存在你自己电脑的文件里，可 diff、可备份、可导出
- **记忆是你的资产**：换模型、换工具、甚至软件死了，记忆文件都还在你手里

## 它具体解决什么

| 痛点 | 灵台 |
|---|---|
| 每个新窗口 AI 都"失忆"，从零考古 | 一段「继续做」指令，任何 AI 三句话接上进度 |
| 教训只活在聊天记录里，换个会话就丢 | 坑库：每条带防法 + **失效判据**（防的事被结构性消除就退休），不是只增不减的清单 |
| 人写的进度表当天就过期 | 状态机器生成，破坏性自检，绿了才信 |
| 越用越膨胀、垃圾清不掉 | 整理页：到期/失效/过期自动浮出，勾选删除 |

## 界面

- **首页一眼看完**：有几个项目装了系统、哪个有告警、经验库多少条、要你处理什么
- **项目卡片**：六器官点阵（绿=新、黄=超 7 天没更新、灰=缺）+ 点进去看进度、复制「继续做」指令、打开目录、一键装系统
- **坑库**：只列「坑 + 怎么防」，点一行才展开出处和失效判据
- **导航只有 2 项**：首页 / 项目库 —— 机器自己维护的东西不占你的导航
- **墨色/宣纸双主题**：默认墨色，朱砂红 + 石青矿物色；左下角一键切

## 怎么拿到

**方式一：下载现成的（推荐，不用装 Python）**

到 [最新版下载页](https://github.com/xieyi138-star/lingtaios/releases/latest) 下载
`lingtaios-vX.Y.Z-win64.zip`，解压到任意目录（**别放 `C:\Program Files` 或桌面临时目录**，
它会在自己旁边写配置和记忆）。目前只有 Windows 64 位版。

> ⚠️ **exe 没有代码签名**，Windows 会弹 SmartScreen「已保护你的电脑」。
> 这是未签名程序的通用提示，不是检出了病毒。要继续：点「更多信息」→「仍要运行」。
> 不放心就走方式二，从源码自己打包——代码全在这儿，你可以先读再跑。

**方式二：从源码自己打包**（需要 Python ≥ 3.8）

```
git clone https://github.com/xieyi138-star/lingtaios.git
cd lingtaios
python -X utf8 install.py          # 探测各根、写 roots.json、补启动器指针
python -X utf8 dashboard.py        # 直接跑源码态，浏览器自动打开
pip install pyinstaller            # 想打成 exe 再装这个
python -m PyInstaller lingtaios.spec
```

`lingtaios.spec` 的路径是自推导的，clone 到哪都能打。打出来在 `dist\lingtaios.exe`。

## 5 分钟上手

1. 双击 `lingtaios.exe`（或 `python -X utf8 dashboard.py`）→ 浏览器自动打开
2. 「＋ 新项目」填表 → 六器官自动装好、状态自动生成
3. 点项目卡 → 复制「继续做」指令 → 粘给任何 AI → 开工
4. 想看进度：双击 → 项目卡；踩坑了：首页「查坑/记坑」

## 换电脑

**用 exe 的**：把 `lingtaios.exe` 所在的**整个文件夹**拷到新机器，双击接着用。
里面有你的配置、方法论文件和记下的坑 —— 只拷 exe 等于重新开始。

**用源码的**：clone → `python -X utf8 install.py` → `python -X utf8 dashboard.py`。

业务数据（本机专属）留原机；方法体系全带走。

## 让方法变得更准

坑库里的每一条都是实战踩出来的。但一个人的实战有边界，**方法要变准，只能靠更多人的现场**。

所以：你在自己项目里记的坑，如果**换一个项目、换一套技术栈还成立**，就一键贡献回主库。

- 界面上记完一条坑 → 点「🌱 贡献回主库」→ 自动带着「坑 / 防法 / 失效判据」开一个 Issue
- 审核通过就进主库，下一版所有人的 AI 都按更准的方法做事
- **被采纳的坑会在坑库里署你的名**（「贡献者」列，也可以选择匿名）
- **不会上传任何东西** —— 它只是替你把内容填进 GitHub 的表单，发不发你自己按

而且判断和起草这两步**不用你做**：「继续做」指令里已经让 AI 干了——
它踩完坑会自己按格式记下来、自己判断通不通用、自己写好贡献草稿，
收工时告诉你「有几条可以贡献回主库」。你只需要看一眼，点一下。

> 为什么是署名不是奖金：金钱激励会挤出内在动机（**小额报酬挤得最狠**），
> 而且必然引来为拿奖励而提交的水货——那会稀释这个库唯一的价值。
> 署名不会。

入库门槛是硬的，和你自己记坑一样：**没有「失效判据」不收**。
判据是让一条坑能退休的唯一机制——防的事被结构性消除了就该删掉，
否则坑库只增不减，最后没人看。

> 判断标准只有一句：**换个项目、换套技术栈，这条还成立吗？**
> 成立 → 进主库。只在你这个项目成立 → 留在你自己的坑库里，同样有用。
